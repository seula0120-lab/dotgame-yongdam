### 시간 결정성 (logic.js 규칙, 기획서 0.60초에서 유도)
- 시간은 정수 밀리초. 한 칸 이동 시간 = 600ms (0.60초).
- 이동 완료 조건: 누적 경과 >= 600. 599에서는 미완료, 600에서 완료.
- 완료 프레임의 초과 시간: 기본 계획(D4 기본값, 키당 한 칸)에서는 버린다. 초과분을 다음 이동으로 넘기는 것(이월)은 D4에서 반복 이동을 사람이 택한 경우에만 적용한다.
- 프레임 dt 상한: 탭 전환 등 큰 dt가 여러 칸을 한 번에 소화하지 않도록 상한을 둔다. 상한값은 기획서에 없다 (D14, 에이전트 제안: 100ms).
- 이동 중 표시 위치는 시작 칸과 도착 칸 사이를 경과/600 비율로 선형 보간 (D6).
- logic 상태에는 from, to, elapsedMs를 둔다.

### D13 제안 격자 (에이전트 제안, 16열 x 12행, 이동 확인용)
문자: `#` 벽, `F` 울타리, `.` 바닥, `S` 달팽이 시작칸. 이 문자 표기 자체도 사람이 서명한다. (격자 문자 S는 키 S와 무관하다.)

```
################
#..............#
#..F...........#
#..F......##...#
#...S..........#
#..............#
#.......FFF....#
#..............#
#..##..........#
#..............#
#..............#
################
```

설계 의도: 바깥 테두리로 맵 가장자리 막힘, 안쪽 벽(`#`)과 울타리(`F`)로 막힘 확인, 시작칸은 열린 공간. 편지·우편함은 없다.

## 7. R1 수용 기준 초안 (사람 서명 후 9장 「R1 항목」에 기재, D8)
번호는 확정 시점에 문서 번호로 바뀐다. R0 스펙 수용 기준 1번(방향키 한 번에 정확히 한 칸, 0.60초)을 채택하고 D2에 따라 WASD를 더한다.
- R1-1. 방향키 또는 WASD를 한 번 누르면 달팽이가 정확히 한 칸, 0.60초 동안 이동한다. WASD는 같은 방향의 방향키와 똑같이 동작한다.
- R1-2. 벽·울타리·맵 가장자리 쪽으로 방향키 또는 WASD를 누르면 달팽이는 움직이지 않는다 (D5 확정 시).
- R1-3. 캔버스 논리 해상도는 256x192이고 화면 표시는 768x576이다.
- R1-4. 맵은 16x12칸이고 타일은 16x16 픽셀이다.
- R1-5. 화면에 쓰인 색은 6장에 확정된 8색뿐이다 (D11 확정 시).
사람이 index.html을 열어 R1-1~R1-5를 직접 확인해야 완료다. 9장에 서명되기 전에는 「완료」라고 말하지 않는다.

## 8. 검증
### node --test (기대값은 기획서 숫자에서 유도, 상수 그대로 옮긴 기본값 테스트는 쓰지 않음)
- 이동 경계: 이동 시작 후 599ms에는 이동 미완료이고 칸 좌표가 그대로, 600ms에서 도착 칸이 입력 방향으로 정확히 1칸 (기대값 0.60초 = 600ms).
- dt 상한: 큰 dt 한 번(예: 10000ms)을 넣어도 이동은 정확히 1칸 (D14 확정 후). 100ms 경과 시 미완료.
- 맵 크기: 레벨 1 격자가 16열 x 12행 (2.1 맵 16x12).
- 해상도 관계: 맵 칸 수 x 타일 크기에서 논리 해상도 256x192가 유도되고, 논리 x 3에서 표시 768x576이 유도된다. 기대값은 문서의 256, 192, 768, 576 리터럴. (상수 값 자체를 되풀이하는 테스트가 아니라 문서 숫자와의 관계 검증.)
- 키→방향 매핑: D2가 문서에 문장으로 들어간 뒤에만 작성. 기대값은 문서 문장의 대응(W=↑=위, A=←=왼쪽, S=↓=아래, D=→=오른쪽): WASD 각 키가 같은 방향의 방향키와 같은 결과(같은 방향으로 정확히 1칸)를 낸다. 키 매핑이 main.js에 있으면 매핑 함수를 logic.js 쪽 순수 함수로 두어 node --test로 검증한다.
- 다중 키: D4-b가 문서에 들어간 뒤에만 작성. 방향키·WASD 두 세트를 모두 덮는다: 예) W+↓ 동시 → 위, ←+D 동시 → 왼쪽, ↑+W 동시 → 위 한 칸(두 칸이 아님). 근거는 서명된 문서 문장.
- 이동 불가: D5가 문서에 문장으로 들어간 뒤에만 작성. 벽·울타리·맵 가장자리 방향 입력 시 위치 불변. 근거는 서명된 문서 문장이다.
- D3·D4 관련 테스트(이동 중 입력 무시, 키 반복 무시)는 해당 문장이 서명된 문서에 들어간 뒤에만 작성하고, 근거 문장을 테스트 주석에 쓴다. 문서 근거 없이는 작성하지 않는다.
- 금지: 코드 동작을 그대로 옮긴 테스트, 기본값 테스트, 근거 없는 테스트. Space·2칸 이동 테스트는 R1에 없다.

### 사람이 확인 (브라우저, index.html 열기)
- 캔버스가 768x576으로 보인다 (R1-3).
- 방향키를 한 번 누르면 달팽이가 한 칸, 약 0.60초에 걸쳐 움직이고 멈춘다. WASD도 같은 방향으로 똑같이 움직인다 (R1-1).
- 벽·울타리·가장자리 쪽 입력에서 방향키·WASD 모두 움직이지 않는다 (R1-2, D5 확정 시).
- 색이 6장에 확정된 8색뿐이다 (R1-5).
- 수용 기준 번호는 9장에 서명된 번호로 보고한다.
